# ⚡ browser-harness: your browser is the harness
> Zero installation, ready in a click, sandboxed by design — the lightest, sleekest browser-native Agent runtime.

👉 **[Try the Live Demo](https://onpanda.diyer22.com/?example=browser-agent)**

---

## 🔥 Why browser-harness?

When testing or using Agents, are you tired of setting up environments, running `npm install`, and manually switching models and effort levels? Or worried that an Agent might mess up your local system?

**browser-harness** brings a complete Agent runtime directly into your browser. It requires no backend environment setup, yet breaks through the limits of traditional web pages — combining **local file access, information gathering, real-time UI rendering, multimedia and hardware I/O, and persistent memory** in one place.

### ✨ Key Highlights (Why Hackers Love It)

* 🛡️ **Zero Installation & Sandboxed by Design**: Say goodbye to setup headaches — open a link and get started. Native browser security boundaries and permissions you control let you confidently put your Agent to work.
* 👁️ **A Visual Feedback Loop You Can See**: Skip the hassle of manually opening and managing HTML/SVG files. The Agent renders pages or images directly in the browser, takes its own screenshots, reflects on the results, and iterates over multiple rounds.
* 📂 **Connect Local Files and Git Repositories with a Drag and Drop**: With modern browser capabilities, simply drag a local folder or code repository into the window. The Agent can inspect and organize files, review code, and even modify uncommitted changes directly.
* ⚡ **A Go-To Tool for Model Vibe Checks**: A full set of tools, an intuitive UI, and configuration you can change at any time make this an ideal playground for testing models' agentic performance on complex tasks that combine multiple capabilities.

## 🎮 What Can It Do? (7 Hands-On Showcases)

Use each capability on its own, or combine them freely to push models to their limits:

### 1. Real-Time Rendering and Visual Self-Reflection (Render, See & Iterate)
* **Generate and iterate on visual creations**: `Use render_svg to draw an SVG of a pelican riding a bicycle, then inspect the image yourself and iterate 3 times.`
* **Gather information and build a complete web page**: `Search for information about StepFun's latest flagship model, then build an introduction page styled like Apple's official website.`
* **Go beyond the host UI**: `What's the weather like today? Build an animated weather card and mount it in the bottom-right corner of the current page.`

### 2. Multimodal Vision and Direct Hardware Access (Multimodal & WebAPI)
* **Use the camera and process images visually**: `Take a photo of me with the camera. Inspect the photo as you crop it to center my face, then draw sunglasses that fit over my eyes and turn it into a photo booth sticker I can download.`
* **Critique a paper's visual design and layout**: `Look at a screenshot of the first page of this paper and critique the design and color choices of Figure 1: https://arxiv.org/pdf/2401.00036`

### 3. Working with Local Files and Code Repositories (Local File & Repo Hacking)
> 💡 *Simply drag a local folder or code repository into the browser window to grant access — securely and under your control.*
* **Review code and fix bugs directly**: `Review the uncommitted changes in the repo I dragged in. If you find any bugs, please fix them and save the changes directly.`
* **Automatically organize a local knowledge base**: `Organize all the PDF files in this folder by topic and move them into the corresponding subfolders. Then generate an index.html that summarizes all the documents.`
